# weDO

weDO is a mobile platform for private group communication, activities, collaboration and shared finance.

## Tech Stack

### Mobile
- Flutter
- Dart

### Backend
- Java 21
- Spring Boot
- Spring Security
- Spring Data JPA
- WebSocket
- Redis

### Database
- PostgreSQL
- Flyway

### Infrastructure
- Docker Compose
- Firebase Cloud Messaging
- Object Storage
